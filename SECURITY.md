# Security policy

## Reporting a vulnerability

Please **do not open a public issue** for security problems.

Use GitHub's private vulnerability reporting instead: go to the repository's **Security** tab and
click **Report a vulnerability**. You will get an answer as soon as possible, usually within a
few days.

## Scope

Coperni is a public, read-only site with no user accounts. Reports are especially welcome about:

- the web application (Django views, the JSON APIs, the place search);
- the GitHub Actions workflows and the deploy path to Google Cloud;
- anything that could expose credentials or allow writing to the data bucket.

The CAMS data itself comes from Copernicus: issues with its content should be reported to
[Copernicus user support](https://atmosphere.copernicus.eu/help-and-support).
